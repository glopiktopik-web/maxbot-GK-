# 🧰 Арсенал мастера — бот-помощник преподавателя для мессенджера MAX

Бот берёт на себя повседневную рутину преподавателя: расписание,
задачи и напоминания, учёт посещаемости, общую базу материалов,
шаблоны отчётов и объявления коллегам.

Написан на Python с библиотекой [maxapi](https://github.com/love-apples/maxapi).

---

## Что умеет

| Раздел | Что делает |
|---|---|
| 📅 **Расписание учебных занятий** | Преподаватель пишет название группы — бот присылает фото расписания. Понимает любой регистр, пробелы, дефисы и латинские буквы вместо русских (`21A` = `21А`). При опечатке предлагает похожие группы, показывает список всех групп по курсам, запоминает «мою группу» и умеет выдавать расписание текстом. |
| 👤 **Моё расписание** | Преподаватель один раз указывает фамилию — и получает свои занятия, собранные из расписаний **всех** групп: на сегодня, на завтра, на неделю. Того, что не видно ни на одной отдельной фотографии. |
| ⏭ **Следующий урок** | Что, где и во сколько: дисциплина, группа, аудитория и обратный отсчёт до начала. |
| 🔔 **Подписка и рассылка** | Бот сам сообщает, когда обновили расписание вашей группы, и может присылать расписание каждое утро в выбранное время. |
| 📝 **Заметки и напоминания** | Записать задачу за 10 секунд и получить напоминание в нужное время («через час», «завтра 8:30», «22.09 09:00»). Отметить выполненной или удалить — кнопкой. |
| ✅ **Посещаемость** | Отметка отсутствующих в три касания: группа → урок → фамилии. Дисциплина подставляется из расписания. Отчёт за неделю или месяц выгружается готовым файлом **Excel** с тремя листами: журнал, сводка по студентам, сводка по группам. |
| 📚 **База материалов** | Общая копилка файлов, презентаций и ссылок с тегами. Один преподаватель добавил — все нашли по ключевому слову. |
| 📊 **Отчёты и шаблоны** | Шесть готовых форм (посещаемость, отчёт классного руководителя, справка о занятии, отчёт о мероприятии, служебная записка, план на неделю) — текстом или готовым документом **Word**. Плюс свои шаблоны и автосводка по задачам за неделю. |
| 📖 **Справочники** | Расписание звонков, список аудиторий, список преподавателей с недельной нагрузкой и поиск свободных аудиторий на нужный урок. |
| 📢 **Объявления** | Рассылка важного сообщения всем коллегам, которые пользуются ботом (для администраторов). |

Команды: `/start`, `/menu`, `/schedule`, `/me`, `/help`, `/cancel`, `/id`.

На `/start` бот присылает приветственный баннер из `assets/welcome.png`.
Картинка загружается на серверы MAX один раз и дальше отправляется
по токену; если файл удалить, приветствие придёт просто текстом.
Квадратный `assets/avatar.png` можно поставить боту на аватар
через @MasterBot.

## Быстрый старт (Windows)

1. Установите **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/),
   обязательно отметив галочку **«Add Python to PATH»**.
2. Получите токен у бота **@MasterBot** в
   мессенджере MAX (`/newbot` → название → токен) и создайте рядом
   файл `.env` со строкой
   `MAX_BOT_TOKEN=ваш_токен` (пример — в `.env.example`).
3. Дважды кликните **`max_bot/run.bat`**.

Скрипт поставит зависимости (только при первом запуске) и запустит бота.
Окно консоли нужно оставить открытым — пока оно работает, работает и бот.
Остановить: `Ctrl + C`.

### Запуск вручную

Откройте командную строку в папке `max_bot` и выполните:

```bat
pip install -r requirements.txt
python bot.py
```

## Два источника расписания

Бот работает с расписанием на двух уровнях, и это важно понимать.

**Картинки** из папки **`schedules`** — первоисточник. Именно их бот
присылает по запросу группы.

```
konkurs\
├── schedules\        ← фотографии расписаний
│   ├── 11А.JPG
│   ├── 21П.JPG
│   └── ...
└── max_bot\          ← сам бот
```

**Имя файла = название группы.** `21П.JPG` → группа `21П`.
Чтобы обновить расписание, просто замените файл — бот заметит изменение
сам, перезапуск не нужен, а подписчики получат уведомление.
Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`.

**Текстовые данные** в `data/timetable.json` — то же расписание, но
разобранное по занятиям: группа, день, урок, дисциплина, аудитория,
преподаватель. Из них собираются личное расписание преподавателя,
«следующий урок», справочники и подсказки при отметке посещаемости.

Сейчас в файле **54 группы, 66 преподавателей, 1875 занятий**.

### Как обновить текстовые данные

Текстовые данные не обновляются автоматически вместе с картинками —
их нужно пересобрать. Исходники лежат в `max_bot/tools/raw/*.txt` в простом
формате, который легко править руками:

```
GROUP 21П
ПН 1 Осн.фин.грам.|315|Мартынова И.М.
ЧТ 5 Иностранный язык|314а|Ковешникова С.В.//Балыкова Л.С.
```

Строка — это `день номер_урока Дисциплина|Аудитория|Преподаватель`,
а `//` разделяет преподавателей первой и второй подгрупп. После правки:

```bat
cd max_bot
python tools\build_timetable.py
```

Бот подхватит новый файл на лету.

Если `data/timetable.json` удалить, разделы «Расписание учебных занятий»,
заметки, материалы и отчёты продолжат работать — просто станут
недоступны разделы, которым нужны структурированные данные.

## Настройки (`.env`)

| Параметр | Назначение |
|---|---|
| `MAX_BOT_TOKEN` | Токен бота из @MasterBot (обязательный, задаётся в `.env`). |
| `SCHEDULES_DIR` | Папка с расписаниями. По умолчанию — `..\schedules`. |
| `ADMIN_IDS` | ID администраторов через запятую — им доступна рассылка объявлений. Свой ID покажет команда `/id` в боте. |
| `ORG_NAME` | Название организации, подставляется в шаблон служебной записки. |

## Структура проекта

```
konkurs/
├── schedules/               фотографии расписаний (первоисточник)
│   ├── 11A.JPG
│   ├── 21П.JPG
│   └── ...
└── max_bot/
    ├── bot.py               точка входа: запуск, команды, обработка ошибок
    ├── config.py            настройки и пути
    ├── loader.py            общие экземпляры Bot и Dispatcher
    ├── db.py                SQLite: пользователи, задачи, материалы,
    │                        шаблоны, посещаемость
    ├── states.py            состояния диалогов (FSM)
    ├── keyboards.py         все инлайн-клавиатуры
    ├── filters.py           фильтры callback-кнопок
    ├── texts.py             тексты и базовые шаблоны отчётов
    ├── utils.py             общие помощники
    ├── handlers/
    │   ├── common.py        старт, меню, справка, отмена
    │   ├── schedule.py      расписание группы картинкой
    │   ├── teacher.py       личное расписание преподавателя
    │   ├── subscribe.py     подписка и утренняя рассылка
    │   ├── attendance.py    посещаемость и отчёт в Excel
    │   ├── notes.py         заметки и напоминания
    │   ├── materials.py     база материалов
    │   ├── reports.py       отчёты, шаблоны и выгрузка в Word
    │   ├── refs.py          справочники
    │   ├── announce.py      объявления
    │   └── fallback.py      сообщения вне диалогов
    ├── services/
    │   ├── groups.py        индекс групп и «умный» поиск по названию
    │   ├── timetable.py     структурированное расписание и запросы к нему
    │   ├── photos.py        отправка расписаний с кэшем загрузок
    │   ├── watcher.py       отслеживание изменений и утренняя рассылка
    │   ├── exports.py       сборка файлов Excel и Word
    │   ├── timeparse.py     разбор времени напоминаний
    │   └── reminders.py     фоновый цикл напоминаний
    ├── assets/
    │   ├── welcome.png      баннер, который бот шлёт на /start
    │   └── avatar.png       квадратная версия для аватарки бота
    ├── tools/
    │   ├── build_timetable.py  сборка data/timetable.json
    │   └── raw/             исходные выгрузки расписаний
    ├── tests/
    │   ├── test_groups.py   поиск группы по названию
    │   └── test_timetable.py  целостность данных и личное расписание
    ├── requirements.txt
    ├── run.bat
    └── .env                 токен и настройки
```

Данные бота хранятся в `data\arsenal.sqlite3` — обычный файл, его можно
скопировать вместе с проектом. Готовые отчёты складываются в
`data\exports`.

## Проверка

```bat
cd max_bot
python tests\test_groups.py
python tests\test_timetable.py
```

Первый тест проходит по реальной папке `schedules` и убеждается, что
каждая группа находится по названию при любом написании. Второй
проверяет целостность текстовых данных, их соответствие фотографиям и
работу личного расписания преподавателя.

## Технические детали

- **Библиотека:** `maxapi` (асинхронная, в стиле aiogram), режим long polling.
- **Хранилище:** SQLite через стандартный `sqlite3` в отдельном потоке —
  никаких внешних баз данных ставить не нужно. Схема обновляется сама:
  новые версии бота дописывают колонки в существующую базу.
- **Расписания:** индекс папки перестраивается автоматически при
  изменении каталога; картинки один раз загружаются на серверы MAX,
  дальше отправляются по токену — это заметно быстрее.
- **Фоновые задачи:** каждые 30 секунд бот проверяет напоминания,
  изменения файлов расписания и время утренней рассылки.
- **Устойчивость:** любая ошибка обработчика логируется и не роняет
  бота; при сбое отправки картинки вместе с клавиатурой бот повторяет
  отправку двумя сообщениями; сбой подтверждения нажатия не мешает
  кнопке отработать.
